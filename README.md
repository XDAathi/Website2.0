# Website 2.0

Personal portfolio built with React, TypeScript, Vite, and Tailwind CSS.

## Scripts

```bash
npm install
npm run dev
npm run build
npm run lint
```

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- react-glass-ui

## Notes

- The site is currently a static frontend.
- The Spotify section uses a direct Spotify embed.
